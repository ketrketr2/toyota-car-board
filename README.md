# 車種別AI分析（CAR × AI DEEP DIVE）

重点8車種（ルーミー／シエンタ／アルファード／ヴォクシー／ノア／アクア／ライズ／ランドクルーザー250）が、
生活者がAIに投げる質問のなかでどれだけ候補に挙がり、第一想起を取れているかを実測するボード。

- 公開ページ: `docs/index.html`（要ログイン。中身は暗号化）
- 計測は [toyota-geo-board](https://github.com/ketrketr2/toyota-geo-board) の `car-round` ワークフローが担当
- 運用手順は `tools/DAILY.md`

推定値・デモ値は表示しない。数値がなければ「—」と出す。
